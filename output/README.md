# Simulation Output Documentation

This document describes the structure, diagnostic contents, and clinical significance of output artifacts generated during the **Diabetic Retinopathy Telemedicine Simulation**.

---

## 1. Output Directory Hierarchy

All simulation run artifacts are saved automatically to `SimulationResults/` in the repository root. Each examined patient receives a dedicated, sequentially numbered folder:

```
SimulationResults/
├── Patient_1/
│   ├── raw.png            # Captured input fundus image (1050x1050x3)
│   ├── processed.png      # Preprocessed network input (224x224x3)
│   ├── gradcam.png        # Grad-CAM explainability heatmap overlay (224x224x3)
│   ├── vessel.png         # Retinal blood vessel segmentation mask (512x512x3)
│   ├── report.txt         # Complete numerical and diagnostic summary
│   └── prescription.txt   # Tele-prescription (created only for referable cases)
├── Patient_2/
├── Patient_3/
└── ...
```

---

## 2. Detailed File Descriptions

### `raw.png`
- **Resolution:** $1050 \times 1050 \times 3$, `uint8`.
- **Purpose:** Represents the initial fundus camera capture passed to the clinical simulation pipeline. Grayscale inputs are converted to 3-channel RGB and alpha channels are stripped.

### `processed.png`
- **Resolution:** $224 \times 224 \times 3$, `uint8`.
- **Purpose:** The image tensor fed into the classification and Grad-CAM networks. Reflects automatic FOV circle cropping, CIE-LAB Luminance CLAHE enhancement, and intensity clamping.

### `gradcam.png`
- **Resolution:** $224 \times 224 \times 3$, `uint8`.
- **Purpose:** Gradient-weighted Class Activation Map (Grad-CAM) overlay. Visualizes the convolutional neural network's attention regions (e.g., microaneurysms, hemorrhages, exudates) in Jet colormap with a 45% transparency overlay.

### `vessel.png`
- **Resolution:** $512 \times 512 \times 3$, `uint8`.
- **Purpose:** High-contrast binary retinal vascular tree mask generated by combining multi-scale Frangi filter responses, Top-Hat morphological enhancement, and deep neural network segmentation.

### `report.txt`
- **Format:** Plain text diagnostic summary.
- **Contents:**
  - `Patient ID`: Sequential identifier.
  - `DR Status`: Categorical triage (`NonReferable` vs `Referable`).
  - `DR Grade`: Categorical ICDR grade (`Grade 0` to `Grade 4`).
  - `Binary Confidence`: Confidence percentage for the binary triage decision.
  - `Grade Confidence`: Confidence percentage for the predicted ICDR grade.
  - `Doctor Review`: Flag (`YES` or `NO`) indicating whether tele-consultation queueing was triggered.
  - `Binary Probabilities`: Full probability distribution for `[NonReferable, Referable]`.
  - `Multi-class Probabilities`: Full probability distribution across `[Grade 0, Grade 1, Grade 2, Grade 3, Grade 4]`.

### `prescription.txt`
- **Trigger Condition:** Generated **only** when `referable == true` and `doctorDone == true`.
- **Contents:** Formal telemedicine prescription and specialist referral recommendations resulting from the simulated remote ophthalmologist consultation.

---

## 3. Git Management of Outputs

> [!NOTE]
> The `SimulationResults/` and `GradCAM_Output/` directories are excluded from Git version control via `.gitignore`. This ensures that local simulation test runs do not pollute the repository with transient binary and text output files.
